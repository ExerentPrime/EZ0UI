ABOUT

EZ0UI is a tool that allows you to easily target and hide specific UI elements on your in-game screen.

DISCLAIMER

1. If you are using your main account to mod, please do so at your own risk.
2. You won't get banned just for using UI modding, but just to be safe, please use a separate account just for modding.
3. For now, this tool has only been tested on two games (Honkai Impact 3rd and Zenless Zone Zero), and it works perfectly.
4. The scripts generated are NOT permanent. When you restart the game, or try it on a different device or with different settings, some UI elements will become visible again.

REQUIREMENT

1. XXMI Launcher or 3DMigoto
2. A second account (Optional but highly recommended)

XXMI/3DMIGOTO SETUP

XXMI SETUP
1. Download the XXMI-Launcher-Portable-vX.X.X.zip here. I recommend the portable version so you can just delete the whole folder when you don't need it anymore.
2. Extract the zip file and put it anywhere you like.
3. Next, create a shortcut for the XXMI Launcher. Go to XXMI-Launcher-Portable-vX.X.X > Resources > Bin, and look for "XXMI Launcher.exe".
4. Right-click on it and select Copy.
5. Navigate to wherever you want to put the shortcut. Then right-click and select Paste Shortcut. NOT regular Paste, got it?
6. Double-click on it to open the XXMI Launcher.
7. Click on the plus icon at the top to install the mods for the games you want.
8. When it's done installing, click on the Settings icon at the top.
9. Click on the XXMI tab on the left side, and check the box for "Enable Hunting".
10. That's it! Now you can click "Start" to open the game.

3DMIGOTO SETUP (Alternative for Genshin if XXMI Launcher is detected as an Illegal Tool)
1. Download 3dmigoto-GIMI-for-playing-mods.zip here.
2. Extract the zip file and put it anywhere you like.
3. Next, create a shortcut for 3DMigoto. Go to 3dmigoto-GIMI-for-playing-mods > 3dmigoto, and look for "3DMigoto Loader.exe".
4. Right-click on it and select Copy.
5. Navigate to wherever you want to put the shortcut. Then right-click and select Paste Shortcut. NOT regular Paste, got it?
6. Double-click on it to open 3DMigoto.
7. A CMD window will appear and wait for you to start the game manually.
8. Go to the game folder, look for GenshinImpact.exe, and double-click on it to start the game without the Hoyoplay Launcher.

HOW TO USE EZ0UI

CREATE THE FRAMEANALYSIS
1. Make sure the Hoyoplay Launcher is not running. Check your taskbar and system tray icons to close it completely.
2. Open XXMI Launcher or 3DMigoto and start the game.
3. The XXMI/3DMigoto GUI will show up; press [F10] to hide it.
4. Go to the screen you want to record.
5. Enable "Hunting Mode" by pressing [Numpad 0] (Default).
6. Press [F8] to create a FrameAnalysis folder. Your screen will freeze for just a moment.
7. The folder is located inside your XXMI/3DMigoto folder. The folder follows this format: FrameAnalysis-YYYY-MM-DD-XXXXXX.

CREATE THE SCRIPT
8. Next, open EZ0UI, click to locate your FrameAnalysis folder, and select the folder.
9. After a second, you will see an image container and some buttons.
10. Navigate through the images by pressing [A/D] on your keyboard.
11. Now you can start looking for all the UI elements you want to remove.
12. To mark a UI element as hidden, press [SPACE] or click on the eye icon.
13. When you are done marking all the UI elements you want to remove, click the "Generate EZ0UI.ini" button to create your script.
14. Place the script in your XXMI/3DMigoto folder under Mods > EZ0UI > EZ0UI.ini. You can rename the folder and file to whatever you like.
15. Now go back to the game and refresh your mods by pressing [F10].
16. To activate the script, press the toggle key [F4] (Default).
17. Done! You should see that the UI elements you marked are now invisible on your screen.
